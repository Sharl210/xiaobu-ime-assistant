# 小布输入法助手

本模块通过 LSPosed 在小布输入法运行时提供界面与交互增强，不修改宿主 APK。目标宿主为小布输入法（`com.oplus.keyboard`）。具体功能是否可用，取决于当前宿主版本是否匹配相应结构，可在模块主界面的 Hook 诊断页查看。

## 功能说明

### 文本编辑面板

将宿主“文本编辑”面板的六个操作按钮重排为两列三行，同时保留宿主控件及其原生点击逻辑：

```text
┌──────────────┬──────────────┐
│  全选／剪切   │      删除     │
├──────────────┼──────────────┤
│    复制      │      回车     │
├──────────────┼──────────────┤
│    粘贴      │     剪贴板    │
└──────────────┴──────────────┘
```

- 左上格根据选择状态在“全选”和“剪切”之间切换。
- 剪切后返回打字主键盘；只有实际粘贴成功才自动返回。
- 使用系统返回手势时回到打字主键盘，不主动收起输入法。

### 剪贴板

- 计数上限显示为 `∞`，解除宿主的条目数量上限。
- 搜索入口只在剪贴板页显示，常用语页不显示；可过滤条目并取消过滤恢复列表。
- 超长条目使用受控预览，复制或编辑仍以完整原文为准。
- 每条增加编辑入口，确认后写回宿主剪贴板数据并刷新。

### 常用语

- 解除正文 500 字限制和条目数量上限。
- 输入、计数和保存仍沿用宿主常用语界面。

### 键盘上滑与符号

- 中文和英文 26 键采用各自的上滑键位与标点形式。
- 中文逗号上滑输入中文感叹号。
- 英文键盘书册图标切换宿主“英文候选”设置；图标状态按设置值显示。
- 中文、英文、数字键盘的“符号”入口目标为宿主完整符号页。
- 主键盘“换行”文字显示为回车箭头，按键行为仍由宿主处理。
- 抑制宿主对引号、括号等输入字符自动补出闭合字符的行为。

### 候选拼音光标

点击组合拼音文本或其右侧空白可选择编辑位置；后续输入和退格围绕该位置执行。光标保留点击占位宽度并闪烁。实际兼容情况以设备操作和诊断日志为准。

### Hook 诊断与日志

主界面右上角的“Hook诊断”打开诊断页，按点位显示：

- 已匹配；
- 安装期匹配失败；
- 尚未收到安装期回传。

点击条目可以查看匹配详情。诊断结果反映定位和回传状态，不等于功能已经通过真机验收。

日志由主界面开关控制：Debug 测试构建默认开启，Release 正式构建默认关闭。用户手动设置后，以用户选择为准；排障时可手动打开，复现后在 LSPosed 日志中筛选 `OplusImePanel`。

## 适配范围与兼容性声明

当前发布包是针对开发阶段已取得并验证过的宿主版本进行适配的版本。模块使用 DexKit 按资源语义、代码字符串、调用关系和成员结构进行通用匹配，尽量减少对混淆类名与方法名的依赖，但这不等于承诺兼容所有宿主版本。

小布输入法不同版本的功能改动较多，资源、数据库、类结构、调用链和 Hook 点都可能发生变化。即使两个版本使用相同的宿主包名，当前版本也可能出现部分功能不可用、诊断点未匹配或需要重新适配的情况。安装前应以当前宿主版本的 Hook 诊断页和实际功能验证为准，不应把“使用 DexKit”理解为“所有版本都能直接使用”。

本次 Release 中保存的 APK，是当前开发阶段适配版本的正式构建包，主要用于当前已验证宿主环境的安装与留档。


- 设备需要 Root 和 LSPosed，并在 LSPosed 中启用模块。
- 作用域只选择小布输入法（`com.oplus.keyboard`），然后重启该输入法进程。
- 本模块不是按手机品牌适配的独立键盘插件。设备必须实际安装兼容的小布输入法，且 LSPosed 能对该进程注入；没有该宿主包时，不会作用于系统自带键盘。
- 宿主版本更新可能改变资源、调用结构或混淆结果，导致个别点位无法匹配；请先查看诊断页与运行日志，不应把安装成功等同于全部功能已生效。
- 停用或卸载模块即可停止运行时介入；模块不修改宿主 APK 文件。

## 安装

1. 安装 GitHub Releases 中的正式 APK，或安装自己构建的 Debug 测试包。
2. 在 LSPosed 中启用“小布输入法助手”。
3. 作用域仅勾选“小布输入法”（`com.oplus.keyboard`）。
4. 重启输入法进程或重启设备。
5. 打开模块主界面查看功能说明与 Hook 诊断。正式版日志默认关闭；需要排障时再手动开启。

## 日志排查

开启模块主界面的日志开关后复现一次问题。日志标签为 `OplusImePanel`，可使用：

```bash
logcat -b all -d | grep OplusImePanel
```

LSPosed 文件日志也可在设备的 `/data/adb/lspd/log/` 中查看。提交问题时请附上宿主版本、模块版本、相关操作步骤和对应时间段日志；日志开关关闭时不会产生模块诊断日志。

## DexKit 定位原则

宿主 Hook 点通过 DexKit 按资源语义、代码字符串、调用关系与成员结构定位；宿主混淆类名和混淆方法名不作为查询条件。安装期解析得到的类与方法只作为本次宿主进程的解析结果缓存。

Android/Java 平台公开 API 的生命周期、输入窗口和视图事件 Hook 属于平台接口，不是宿主混淆点。宿主功能模块均从 `DexKitBridge` 查询，或由已查询到的宿主类继续按成员结构筛选；没有把宿主混淆类路径、混淆方法名或 `getItem(int)` 作为宿主定位条件。

诊断页用于展示当前设备上的匹配和回传状态；宿主大版本变化后仍需实际回归。

## 自行构建

环境：Gradle 8.10.2、AGP 8.6.1、Kotlin 1.9.24、compileSdk 34。

```bash
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
```

产物分别位于 `app/build/outputs/apk/debug/` 与 `app/build/outputs/apk/release/`。Debug 默认日志开启，Release 默认日志关闭。构建需要本机 Android SDK；`local.properties` 不纳入版本控制。
